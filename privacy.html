隐私政策

Privacy Policy · 更新日期：2026 年 11 月 3 日

1. 适用范围与当前状态

本政策适用于山海祈愿树 Windows 本地场景工具及本政策页面。当前软件版本处于本地模拟模式，不连接 TikTok，也不收集真实 TikTok 观众的进场、评论或礼物数据。所有演示用户和互动都是模拟数据。

2. 本地软件处理的数据

为运行和恢复本地场景，软件可能在你的电脑上保存模拟用户编号、模拟昵称、可选的模拟头像地址、祈愿主题、模拟评论指令、模拟礼物测试摘要、角色状态、祈愿牌、事件日志和管理员设置。数据保存在本地 SQLite 数据库及项目的数据目录中，由运行本软件的设备使用者管理。

请勿在模拟昵称或评论中输入真实姓名、联系方式、住址、生日、生辰八字、健康资料或其他敏感信息。软件不要求此类资料，也不提供个人命理分析。

3. 数据传输与可选语音

当前模拟功能不会把本地互动记录发送给本项目运营者；本项目没有远程应用服务器，也没有真实 TikTok 事件连接。

管理员可选择是否单独配置 Azure AI Speech。只有在管理员配置凭据并启用 Azure 合成时，送去合成的播报文本（可能包含模拟昵称和祝福内容）才会发送给 Microsoft Azure。凭据保存在本机配置中，不应公开或提交到代码仓库。Azure 对相关数据的处理遵循其自身的服务条款和隐私政策。

主题音乐及其他导入素材保存在本机。请仅导入你拥有或获准使用的内容。

4. 保存与删除

本地数据会保留在该设备上，直到使用者通过软件提供的管理功能清理或重置，或自行删除项目数据。清理浏览器缓存不会自动删除本机 SQLite 历史数据。请在重置前备份希望保留的内容。

5. 本政策网站

如果本政策页面通过 GitHub Pages 发布，GitHub 作为网站托管服务提供方可能按其自身政策处理访问该网站所需的技术信息。政策页面本身不设置广告追踪器、分析脚本或用户账号。

6. 儿童与第三方服务

本软件不是面向儿童设计的服务。可选的 Azure 语音功能由 Microsoft 提供，并受其政策约束。除明确启用的第三方功能外，本地模拟应用不会主动向第三方发送模拟互动记录。

7. 你的选择与联系

你可以不输入任何个人信息，并可通过本机管理功能清理模拟记录。若你对隐私有疑问或希望提出请求，请联系：ilikefreedom6075@gmail.com。

8. 政策更新

若数据处理方式发生实质变化，本政策应在新功能启用前更新。更新日期会显示在本页顶部。
